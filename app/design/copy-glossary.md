# Copy glossary (prototype)

Read by `npm run lint:copy` (`--glossary`). The canonical glossary and its reasons are in
[UI text](../../docs/design/ui-text.md#glossary-additions); this table holds only the terms the
linter can check. Keep both in step. "Wiki" is not linted because the required disclaimer names
the community wiki; the product itself is never called a wiki.

| Term | Meaning | Use instead of |
|---|---|---|
| Codex | The collection of everything in the game | Encyclopedia, Database |
| Hidden secret | An item protected from spoilers until the person reveals it | Locked |
| Pin to run | Keep items in view during a run | Track, Follow |
| Run companion | Focus mode during a run | HUD, Live mode |
| What's new | Changes since the last visit | Patch notes |
